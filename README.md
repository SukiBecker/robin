# Robin

Grundgerüst für Robin V1, eine gamifizierte Lern-App.

## Lokales Setup

```bash
npm install
npm run dev
```

Anschließend ist die App unter `http://localhost:3000` erreichbar.

Die vorbereiteten Umgebungsvariablen stehen in `.env.example`. Für die lokale Nutzung kann diese Datei bei Bedarf nach `.env.local` kopiert und mit eigenen Werten ergänzt werden.
